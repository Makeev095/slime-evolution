# Слайм: Эволюция

Кликер для **Яндекс Игр** на Phaser 3. Тапай слайма, покупай помощников, эволюционируй через 7 стадий
(капелька → слайм → рыцарь → маг → дракон → космонавт → бог) и перерождайся за эссенцию.

Вся графика и звук генерируются кодом (canvas + Web Audio): в игре нет внешних картинок и аудиофайлов.

## Что внутри

- **Тап** со squash-анимацией, критами, комбо и режимом «Ярость».
- **12 помощников** (💧 Капельница … 🕳️ Чёрная дыра): до открытия — чёрные силуэты «???» без подсказки, сколько нужно копить; множитель x2 на вехах (10/25/50/…). Покупка всегда по одной штуке (без «x10 / x100 / MAX»); удержание строки быстро повторяет покупку.
- **Долгий финал**: последние два помощника (⭐ Звезда, 🕳️ Чёрная дыра) стоят десятки триллионов и квадриллионы; по симуляции активного игрока Звезда покупается примерно на 25-й час, Чёрная дыра — на 50-й. Первые уровни открываются за минуты.
- **Счётчик желе с двумя знаками после запятой** (до 100 тысяч): видно, как «капает» в реальном времени.
- **Эволюция** слайма: 7 стадий, у каждой свой вид, фон, декор и множитель дохода.
- **Перерождение** за эссенцию (+10% к доходу за каждую).
- **Золотые пузыри**, подарок раз в несколько минут, ежедневная награда (серия дней). Желе капает только пока игрок в игре: дохода «пока тебя не было» нет.
- **Кристаллы** (мягкая премиум-валюта): трата на ускорения времени и турбо; их можно получить за просмотр видео или купить.
- **Реклама**: межстраничная только в естественных паузах (с обратным отсчётом 3-2-1), обычно не чаще раза в 2 минуты; на поздних стадиях игры пауза короче (105 / 90 / 75 с, настраивается в `CONFIG.ads.intervalByStageMs`),
  rewarded — только за реальное действие, награда выдаётся строго в `onRewarded`.
- **Покупки** (Яндекс Платежи, с `consumePurchase` для расходуемых и восстановлением необработанных при старте).
- **Сохранения**: облако Яндекса + localStorage, побеждает более свежее (`updatedAt`).
- **Две раскладки**: на телефоне магазин внизу; на широком экране (компьютер, планшет) магазин слева крупными карточками на отдельной камере, слайм справа. Переключается на лету при повороте/изменении окна.
- **Языки**: русский, английский, турецкий. Язык берётся из Яндекса, игрок может сменить его кнопкой с флагом (выбор сохраняется).
- **Шрифт** Nunito (SIL OFL, `fonts/OFL.txt`) — круглый, с кириллицей и турецкими буквами.

## Товары для консоли Яндекс Игр (Монетизация → Внутриигровые покупки)

| ID | Тип | Что даёт | Цена в игре (dev) |
|---|---|---|---|
| `gems_100` | расходуемый | 100 кристаллов | 30 Ян |
| `gems_550` | расходуемый | 550 кристаллов | 150 Ян |
| `gems_1800` | расходуемый | 1800 кристаллов | 450 Ян |
| `x2_forever` | постоянный | доход x2 навсегда | 199 Ян |
| `no_ads` | постоянный | отключает межстраничную рекламу | 99 Ян |

ID должны совпадать буква в букву. Цены и иконки (256x256) задаются в консоли.

## Запуск

```sh
python3 -m http.server 8781 --bind 127.0.0.1   # из корня проекта
# открыть http://127.0.0.1:8781/index.html
# ?debug — открывает window.__game и window.__slime для отладки
```

Вне Яндекса (нет `/sdk.js`) игра сама уходит в dev-режим: реклама и покупки имитируются, сохранения — в localStorage.

## Сборка архива для консоли

```sh
sh build.sh      # → slime-evolution.zip (index.html в корне, Phaser локально)
```

SDK подключается относительным путём `/sdk.js` (так требует модерация для архива).

## Тесты

```sh
node tests/economy.test.js                          # экономика, языки, форматы, темп игры
node tests/sim.js 60                                # симуляция активного игрока (когда что открывается)
npm i puppeteer-core                                 # нужен установленный Google Chrome
python3 -m http.server 8781 --bind 127.0.0.1 &
NODE_PATH=./node_modules node tests/e2e.cjs [фильтр]  # сценарии в браузере с мок-SDK
NODE_PATH=./node_modules node tests/gallery.cjs stages|ui
```

Сценарии: тапы, широкая раскладка, языки, счётчик, интервал рекламы, улучшения, эволюция, ежедневная награда, реклама (dev и мок SDK), золотой пузырь,
магазин, кристаллы, перерождение, отсутствие офлайн-дохода, сохранения (в т.ч. битые данные), звук, сенсорный ввод, раскладки разных экранов.

```
src/i18n.js           тексты ru / en / tr
fonts/                шрифт Nunito (woff2)
src/scenes/           Boot, Play, Shop
tests/                юнит- и браузерные тесты
```
